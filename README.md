# Phishing Email Investigation Lab

## Project Overview
This project simulates a real-world Security Operations Center (SOC) investigation involving a suspected phishing email.

The objective is to investigate suspicious email characteristics, document indicators of compromise (IOCs), assess potential risks, and recommend appropriate incident response actions.

## Objectives
- Identify suspicious email characteristics.
- Analyze available indicators of compromise.
- Document findings and supporting evidence.
- Prepare an incident investigation report.
- Recommend appropriate security response actions.

## Tools
- GitHub
- VirusTotal
- URLScan.io
- CyberChef

## Project Status
In progress — investigation and documentation are being developed using simulated data.

## Disclaimer
This is an educational project. The organization and email samples are fictional. No unauthorized systems or real user accounts are involved.
